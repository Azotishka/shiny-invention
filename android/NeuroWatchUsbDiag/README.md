# NeuroWatch USB Diagnostic for Android

Read-only диагностическое приложение для первого безопасного этапа установки NeuroWatch OS без компьютера.

## Важное уточнение по аппаратной ревизии

Физические часы пользователя имеют USB-C, тогда как официальная Watchy V2 документирована с Micro-USB. Поэтому до чтения USB VID/PID аппаратную ревизию считаем **неподтверждённой** и не разрешаем прошивку по профилю V2.

## Что делает

- проверяет поддержку Android USB Host;
- перечисляет USB-устройства через официальный Android USB Host API;
- показывает VID/PID и количество интерфейсов;
- отмечает Silicon Labs CP2102 `10C4:EA60` (классическая Watchy V2);
- отмечает Espressif USB Serial/JTAG `303A:1001` (ESP32-S3 / типичный путь Watchy V3);
- показывает и неизвестные USB-устройства, чтобы не отбрасывать клоны или другие ревизии.

## Чего не делает

- не переключает ESP32 в bootloader/download mode;
- не использует DTR/RTS;
- не открывает serial port;
- не читает и не записывает Flash;
- не выполняет erase;
- не устанавливает NeuroWatch OS.

Если Android вообще не перечисляет часы, переходить к прошивке нельзя. Сначала нужно подтвердить физическое USB data-соединение и идентифицировать аппаратную ревизию.

После успешного обнаружения USB-интерфейса следующим этапом будет отдельный read-only модуль резервного копирования Flash.
