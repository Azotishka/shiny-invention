# NeuroWatch USB Diagnostic for Android

Read-only диагностическое приложение для безопасной подготовки NeuroWatch OS без компьютера.

## Подтверждённый USB-интерфейс конкретных часов

На Xiaomi Pad 7 Pro физические часы определились как:

- VID `1A86`
- PID `55D4`
- USB class 2
- 2 interfaces

Это соответствует WCH/QinHeng CH9102 USB-UART. Значит USB OTG, кабель и линии DATA работают. При этом точная ревизия самих часов и тип ESP-чипа ещё не подтверждены, поэтому прошивка по профилю Watchy V2 пока запрещена.

## Что делает v0.2

- проверяет Android USB Host;
- перечисляет USB-устройства;
- показывает VID/PID и количество интерфейсов;
- распознаёт WCH CH9102 `1A86:55D4`;
- также знает CP2102 `10C4:EA60` и Espressif USB Serial/JTAG `303A:1001`.

## Чего не делает

- не переводит ESP в bootloader/download mode;
- не использует DTR/RTS;
- не открывает serial port;
- не читает и не записывает Flash;
- не выполняет erase;
- не устанавливает NeuroWatch OS.

Следующий этап — отдельная read-only проверка serial-соединения и идентификация микроконтроллера перед любым резервным копированием или прошивкой.
