# NeuroWatch USB Diagnostic for Android

Read-only диагностическое приложение для первого безопасного этапа установки NeuroWatch OS без компьютера.

## Что делает

- проверяет поддержку Android USB Host;
- перечисляет USB-устройства через официальный Android USB Host API;
- показывает VID/PID и количество интерфейсов;
- отдельно отмечает Silicon Labs CP2102 `10C4:EA60`, используемый Watchy V2.

## Чего не делает

- не переключает ESP32 в bootloader/download mode;
- не использует DTR/RTS;
- не открывает serial port;
- не читает и не записывает Flash;
- не выполняет erase;
- не устанавливает NeuroWatch OS.

Если Android не перечисляет CP2102, переходить к прошивке нельзя: сначала нужно исправить физическое USB-соединение (data-кабель/разъём/USB-UART).

После успешного обнаружения CP2102 следующим этапом будет отдельный read-only модуль резервного копирования Flash.
