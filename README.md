# NeuroWatch OS v1.0

Прошивка для Watchy V2 / ESP32-PICO-D4 с крупным русским меню, тёмной темой, вибробудильником, шагомером, играми и синхронизацией времени по Bluetooth с iPhone или Android.

## Язык, тема и игры

- Русский язык включён по умолчанию; в **МЕНЮ → ЯЗЫК** можно переключить интерфейс на английский.
- **Тёмная тема** меняет цвета всего интерфейса и сохраняется после перезапуска.
- Меню состоит из пяти коротких разделов. Основные пункты и показания используют увеличенный жирный шрифт.
- В разделе **ИГРЫ** доступны кубик, реакция, монетка, угадывание числа и быстрый счёт. Тест реакции сохраняет рекорд.
- В **ШАГИ И ПРИЛОЖЕНИЯ** есть секундомер и короткая дыхательная практика. Экран секундомера обновляется раз в пять секунд для экономии батареи.
- На циферблате **ВВЕРХ** открывает шаги, **ВНИЗ** — заряд, статус часов и будильник.
- Вибрацию будильника можно настроить отдельно и проверить пунктом **ТЕСТ ВИБРАЦИИ**.

## Синхронизация времени

1. Установи приложение NeuroWatch Connect на телефон.
2. На часах открой **МЕНЮ → ВРЕМЯ И ДАТА → ВРЕМЯ С ТЕЛЕФОНА**.
3. В приложении нажми **Синхронизировать** и дождись подтверждения.

Часы получают дату, местное время и UTC-смещение телефона. Начальное смещение — UTC+05:00 (Екатеринбург). После смены часового пояса синхронизируй часы повторно. BLE включается только по запросу и выключается после успешной синхронизации, отмены или тайм-аута.

## Будильник

В меню доступны включение будильника, время срабатывания, независимая настройка **ВИБРОБУДИЛЬНИК** и проверка **ТЕСТ ВИБРАЦИИ**. Сигнал будильника использует два заметных импульсных цикла; он срабатывает не более одного раза за местный календарный день. Будильник изначально выключен.

## Беспроводное обновление с iPhone и Android

**Первую установку v1.0 сделай через USB** с Android-планшета или компьютера: прошивка v0.9 ещё не имеет Wi-Fi-загрузчика. После установки открой **МЕНЮ → СИСТЕМА И ОБНОВЛЕНИЕ → ОБНОВИТЬ ПО WI-FI**. Часы проверят запасной раздел прошивки и заряд не ниже 50%, затем покажут имя временной сети, случайный пароль и адрес `http://192.168.4.1`.

Подключи iPhone или Android к сети часов, открой адрес в Safari/Chrome, выбери **NeuroWatch-OS-v1.0-app.bin** из файлов и дождись сообщения об успехе и перезагрузки. Интернет не нужен. Сеть работает только по запросу и выключается через пять минут бездействия или при выходе. Если часы сообщают, что разметка памяти не подходит, продолжай обновлять по USB. USB также нужен для восстановления, если новая прошивка не запускается: аппаратный откат не подтверждён.

## Файлы сборки

- USB-установщик Android собирается как `NeuroWatch-Updater-v1.2.apk`; в нём есть app-образ v1.0. Версия v1.2 читает таблицу разделов штатным загрузчиком esptool в RAM, проверяет полноту ответов и изолирует USB-сеансы при переподключении.
- Приложение Bluetooth-синхронизации Android остаётся совместимым с протоколом v0.9.
- iOS-исходник для Xcode и проект XcodeGen собираются отдельно; для запуска на iPhone нужен Mac с Xcode и подписью приложения.
- Прошивка выпускается как app-only BIN для Wi-Fi-загрузки и установленного USB-обновителя.

Инструкции по приложению: [`mobile/README.md`](mobile/README.md). Архитектура и протокол: [`docs/superpowers/specs/2026-09-27-neurowatch-phone-sync-design.md`](docs/superpowers/specs/2026-09-27-neurowatch-phone-sync-design.md).

## Сборка

GitHub Actions запускает Python-тесты, собирает прошивку на закреплённых версиях Arduino ESP32 и Watchy, проверяет размер app-образа, собирает Android APK и проверяет iOS-пакет и симуляторную сборку.

Успешная CI-сборка подтверждает компиляцию и размер, но не заменяет испытание на физических часах. Обновление Wi-Fi проверяет установленную разметку при запуске и пишет только в запасной раздел. Файл app-only BIN не содержит загрузчик или таблицу разделов.
